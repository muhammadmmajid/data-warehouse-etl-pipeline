# Data Warehouse & ETL Pipeline

## Overview
Built a data warehouse and ETL pipeline to process and transform large datasets into structured formats for reporting and analysis.

## Technologies Used
- SQL (Oracle, SQL Server)
- Talend Open Studio

## Key Features
- Designed star schema with fact and dimension tables
- Built ETL pipelines to extract, transform, and load data
- Processed 70,000+ records with validation checks
- Implemented data cleaning (duplicates, date filtering, foreign key checks)
- Generated automated rejection logs

## Outcome
Improved data accuracy and created a structured system for reliable reporting and analytics.
